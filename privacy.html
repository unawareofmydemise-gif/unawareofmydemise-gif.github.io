Gizlilik Politikası

YouTube Yöneticisi, yalnızca sahibinin kendi YouTube kanalına erişen kişisel bir araçtır. Google hesabıyla verilen izinle YouTube Data API ve YouTube Analytics API üzerinden kanal, video ve oynatma listesi bilgilerini okur; sahibinin onayladığı değişiklikleri uygular.

Okunan veriler yalnızca sahibinin özel GitHub deposunda saklanır. Hiçbir veri üçüncü kişilerle paylaşılmaz, satılmaz veya reklam amacıyla kullanılmaz.

Erişim izni istenildiği zaman Google hesap izinleri sayfasından geri alınabilir. Uygulama, YouTube Hizmet Şartları ve Google Gizlilik Politikası kapsamında YouTube API Hizmetlerini kullanır.

Privacy Policy

YouTube Manager is a personal tool that only accesses its owner's own YouTube channel. With the permission granted through the Google account, it reads channel, video and playlist data via the YouTube Data API and YouTube Analytics API and applies changes the owner approves.

Data is stored only in the owner's private GitHub repository. No data is shared with third parties, sold, or used for advertising.

Access can be revoked at any time at Google Account permissions. The app uses YouTube API Services under the YouTube Terms of Service and the Google Privacy Policy.
